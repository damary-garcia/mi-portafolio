# Mi portafolio

Portafolio personal de Diana García con presentación, habilidades y proyectos. Está hecho solo con HTML y CSS, sin frameworks ni dependencias que instalar.

## Estructura

```
mi-portafolio/
├── index.html    ← Página principal
├── styles.css    ← Estilos (tema oscuro)
├── foto.jpg      ← Foto de perfil
├── img/          ← Capturas de los proyectos
│   ├── control-gastos.png
│   └── juego-energia.png
└── README.md     ← Descripción del proyecto
```

## Contenido de la página

- **Presentación:** nombre, foto, descripción corta y botones a GitHub y LinkedIn.
- **Habilidades:** TypeScript, HTML y CSS, patrón MVC, documentación técnica y trabajo en equipo.
- **Proyectos:**
  - Control de Gastos Simple (TypeScript, MVC, localStorage).
  - Juego educativo de energía eléctrica para niños.
- **Contacto:** enlaces a LinkedIn y GitHub.

## Cómo verla

1. Descarga o clona el repositorio.
2. Abre `index.html` en el navegador (doble clic).

No necesita servidor ni instalación.

## Características

- Tema oscuro con degradados violeta y cian.
- Diseño responsive: se adapta a celulares y pantallas grandes.
- Animaciones suaves que se desactivan si el dispositivo lo pide.
- Espacio para la captura de cada proyecto.
- Foto de respaldo si `foto.jpg` no se encuentra.

## Personalización

- Guarda tu foto como `foto.jpg` en la raíz de la carpeta.
- Guarda las capturas en `img/` con los nombres `control-gastos.png` y `juego-energia.png`.
- Cambia los enlaces "Ver código" por la URL de cada repositorio.
- Ajusta los colores en las variables de `:root` al inicio de `styles.css`.
